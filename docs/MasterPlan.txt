# MASTER IMPLEMENTATION PLAN — LUNARA SILVER

## 1. Tổng quan dự án

**Tên dự án:** Lunara Silver
**Loại hệ thống:** Website thương mại điện tử trang sức bạc
**Mục tiêu:** Xây dựng website bán hàng Lunara Silver chuyên nghiệp, hiện đại, responsive, có đầy đủ chức năng e-commerce cơ bản, đồng thời đáp ứng toàn bộ yêu cầu đồ án Laravel.

Website không được triển khai theo kiểu chỉ đủ CRUD để nộp bài. Kiến trúc phải đủ sạch để có thể tiếp tục mở rộng Cloudinary, VNPay và các chức năng bán hàng nâng cao mà không phải xây lại hệ thống.

### Công nghệ bắt buộc

* Laravel
* PHP
* MySQL
* Eloquent ORM
* Migration
* Seeder
* Blade Template
* Bootstrap
* JavaScript / Fetch API cho AJAX
* Laravel Middleware cho phân quyền
* Cloudinary cho media
* VNPay tích hợp sau khi website bán hàng cơ bản hoàn thiện

### Role tối thiểu

* `admin`
* `user`

Không cần xây dựng hệ thống permission phức tạp ở phiên bản đầu.

# 9. Ảnh Collection — hover swap

Collection có cấu trúc:

```text
set 1(1)
set 1(2)
```

Ý nghĩa:

```text
set 1(1) = primary image
set 1(2) = hover image
```

Khi product card bình thường:

```text
Primary image
```

Khi hover:

```text
Primary image
↓ fade
Hover image
```

Transition đề xuất:

```text
200–300ms
```

Không zoom quá mạnh.

Ví dụ:

```text
LNS-SET001

primary
media/Collection/set 1(1).jpg.png

hover
media/Collection/set 1(2).png
```

Tương tự cho các set còn lại.

# 31. Checkout transaction

```text
BEGIN
↓
validate cart
↓
check stock
↓
create order
↓
create order items
↓
decrease stock
↓
create payment record
↓
clear cart
↓
COMMIT
```

Nếu lỗi:

```text
ROLLBACK
```
